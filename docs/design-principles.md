# Design Principles

The north star: **the app should feel friendly to someone who finds the gym intimidating.**

## 1. One-thumb operation
Everything you do mid-workout must be reachable with one thumb. Tap targets ≥ 56dp. No tiny gear icons during a set.

## 2. Big, calm, and quiet
Default to a calm palette. Loud accent colors are reserved for celebrations (PRs, finishing a workout). No red "DANGER" energy.

## 3. Defaults that work
A new user should be able to start training within 60 seconds of opening the app. Smart defaults > a hundred preferences.

## 4. Show, don't tell
Every exercise has a short looping visual. Words alone aren't enough for beginners.

## 5. Never shame
No streak guilt, no "you missed a workout" red badges, no comparison to other users. Encouragement only.

## 6. Honest progress
Charts show real data. No vanity metrics. No XP. No levels.

## 7. Privacy by default
Data lives on device. Cloud sync is opt-in and (eventually) self-hostable.

## 8. Performance is a feature
60fps animations. Logging a set never blocks on the network. App opens in < 1s on a 5-year-old phone.
